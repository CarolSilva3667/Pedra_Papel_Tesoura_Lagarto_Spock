# Pedra_Papel_Tesoura_Lagarto_Spock

## Descrição
O Projeto Pedra, Papel, Tesoura, Lagarto, Spock é uma versão simples e intuitiva da versão presente na série The Big Bang Theory. Nele o jogador ira jogar contra o computador.

## Regras do Jogo

- ✊ Pedra quebra Tesoura e esmaga Lagarto
- ✋ Papel cobre Pedra e refuta Spock
- ✂️ Tesoura corta Papel e decapita Lagarto
- 🦎 Lagarto envenena Spock e come Papel
- 🖖 Spock vaporiza Pedra e quebra Tesoura

---

## Tecnologias Utilizadas

- HTML
- CSS
- JavaScript

---

## Como Executar

1. Clone este repositório:

```bash
git clone https://github.com/seu-usuario/Pedra_Papel_Tesoura_Lagarto_Spock.git
```

2. Abra a pasta do projeto.

3. Execute o arquivo `index.html` no navegador.
